## 지금 들어있는 기능

- **재료 5종:** 연강 · 고장력강 · 콘크리트 · 목재 · 고무. 재료별 설명이 상시 표시되고, 용어도 재료에 맞춤 (항복 / 균열 / 비례한도 / 선형한계)
- **하중물 5종:** 시험추 100, 적재블록 500, 작업자 75, 차량 1,500, 중장비 5,000 kg
  - 드래그로 위치 지정 (놓일 x와 추가될 M을 미리 보여줌)
  - 클릭하면 끝단부터 자동 배치
  - 3D 화면에서 클릭하면 개별 제거
- **거동:** 탄성 → 소성(영구 처짐, 윗면 주황 띠) → 파괴
  - 연성: 크게 휜 뒤 고정단에서 끊어짐
  - 취성: 예고 없이 깨짐
- **파괴 순간 재구성:** 마지막 하중의 몇 %에서, 또는 두께 몇 cm에서 σ_u 에 도달했는지 계산해 표·σ-ε 선도·BMD·하중 목록을 모두 그 순간 기준으로 보여줌
- **σ-ε 선도:** 현재 점, 하중 제거 경로, 잔류 변형률, εy·εu·εf 눈금, 탄성구간 확대 표시
- **휨모멘트도(BMD):** 재료별 한계모멘트선 포함. 하중 목록에 P·x 기여분과 합계, 수치표, 응력 게이지
- **두께 h 슬라이더:** I ∝ h³, S ∝ h². 소성·파괴가 일어난 뒤 바꾸면 새 시편에 같은 하중을 다시 올림
- **화면 변형 확대:** 재료별 자동 배율 (연강 ×10 등). 화면 배지를 클릭해 바꿀 수 있고, 표의 수치는 항상 확대 없는 값
- **재료 전환:** 같은 하중을 새 시편에 다시 올려 재료끼리 비교할 수 있음
- **🎯 실험 미션 5개:** 취성 파괴 / 영구 처짐 / 고무 복원 / M=P·x / 두께 효과
- **기타:**
  - 첫 사용 안내 말풍선과 💡가이드 (사용법, 개념, 계산 가정)
  - 휴대폰·태블릿 레이아웃
  - 키보드 접근 (도크와 미션 버튼)
