# 버텨라 캔틸레버 (Voxel Cantilever Lab)

구조역학 수업 과제 — **응력-변형률 선도** 개념을 직접 체험하는 게임형 시뮬레이터.
왼쪽 땅의 낭떠러지 끝에 고정된 캔틸레버 다리(보)에 하중물을 올려, 재료에 따라 **탄성 → 소성 → 파괴**가 어떻게 다르게 나타나는지 관찰한다. 다리가 부러지면 아래 호수로 떨어진다.

## 실행

```bash
python serve.py          # → http://localhost:8000/index.html
```

`index.html` 을 브라우저로 바로 열어도 동작한다 (Three.js 는 `three.min.js` 로컬 파일 사용).
`serve.py` 는 캐시를 꺼서, 파일을 고친 뒤 새로고침하면 항상 최신 버전이 보이게 한다.

## 사용법

1. 아래 **부재 설정**에서 **재료** 선택 (연강 · 고장력강 · 콘크리트 · 목재 · 고무) 와 **두께 h**
2. 아래 도크의 **하중물**을 보 위로 끌어다 놓기 (클릭하면 끝단부터 자동 배치)
   - 드래그 중에 놓일 위치 `x` 와 추가될 모멘트 `+P·x` 가 미리 보인다
3. 보의 휨과 오른쪽의 **σ-ε 선도**·**휨모멘트도(BMD)**·안전모 캐릭터의 **실시간 대사**·**실시간 역학 상태**·하중 목록의 `P·x` 를 관찰
   - σ-ε 선도를 누르면 **휨응력 σ = M/S 와 단면계수 S = bh²/6** 개념 페이지가 열린다
4. 보 위 하중물을 **끌어서 위치를 옮기면** M 과 휨이 실시간으로 바뀐다 (클릭하면 하나씩 제거)
5. **[❌ 하중 전부 제거]** 로 원래대로 돌아오는지(탄성) / 처진 채 남는지(소성) 확인, **두께 h** 슬라이더로 단면 효과 비교
6. 왼쪽 **🎯 실험 미션** 12개를 완료하며 **점수**(만점 1,330점) 모으기
7. 오른쪽 맨 아래 **[🏁 실험 종료 · 점수 확인]** 으로 점수·등급을 보고 이름을 적어 **랭킹**에 등록 (이 브라우저의 localStorage 에 저장. 서버 랭킹으로 바꾸려면 `RANKING_ENDPOINT` 에 주소를 넣으면 등록 때 POST 한다)

## 화면 구성

| 영역 | 내용 |
|---|---|
| 3D 화면 | 기본은 정면(단면) 시점, 빈 곳을 끌거나 [🧊 아이소뷰] 버튼으로 돌려 보기. 낭떠러지에 고정된 복셀 캔틸레버 다리와 그 아래 호수(먼 배경은 그림 한 장), 응력 히트맵(빨강=고응력), 소성 흔적(보 윗부분 주황 띠), 보 아래 거리 라벨 |
| 왼쪽 열 | 🎯 실험 미션 12개(점수·진행바), 완료 메모. 좁은 화면에서는 접히는 카드 |
| 오른쪽 열 | σ-ε 선도(작동점·잔류변형률·하중 제거 경로, 단면계수식, 클릭하면 개념 페이지), BMD, 실시간 대사, 실시간 역학 상태 표, 응력 게이지, 하중 목록, 맨 아래 [하중 전부 제거]·[시편 교체]·[🏁 실험 종료] |
| 하단 바 | 왼쪽 **하중물 도크** (시험추 100 kg · 적재블록 500 kg · 작업자 75 kg · 차량 1,500 kg · 중장비 5,000 kg) + 오른쪽 **부재 설정** (재료, 두께 h, 화면 휨 배율) |
| 종료 모달 | 점수·미션 달성·등급(견습→마스터 엔지니어), 랭킹표(상위 10) |

## 계산 모델 (교육용 단순화)

- 보: L = 6 m, b = 0.18 m, h = 0.15~0.45 m, 집중하중, 자중 무시
- 모멘트 `M(x) = Σ P_i (x_i − x)`, 응력 `σ = M / S`, `S = b h² / 6`, `I = b h³ / 12`
- 탄성 처짐: 오일러-베르누이 보 이론 (표의 '실제' 수치)
- 소성: σ-ε 곡선에서 잔류 소성변형률 `ε_p = ε(σ) − σ/E` → 잔류 곡률 `κ_p = 2ε_p / h` 를 위치별 **최대 이력**으로 저장
- 파괴: 고정단 응력이 극한강도 σ_u 에 도달하면 파괴 (연성: 크게 휜 뒤 파단 / 취성: 예고 없이 깨짐)
  - 파괴 순간 재구성: 마지막에 올린 하중의 α 배 / 두께가 h_cr 까지 얇아졌을 때 / 끌어 옮기던 하중이 x_cr = (M_u − M_나머지)/P 에 왔을 때
- 화면의 휨 모양만 재료별로 확대(연강 ×10 등)해서 보여주고, 표의 수치는 항상 실제값

python test_mechanics.py   # 손계산 공식 검증 + 재료별 항복/파괴 하중 기준표
python run_e2e_test.py     # 헤드리스 Chrome 44개 시나리오 (드래그·클릭·키보드, 하중 끌어 옮기기, 단면↔아이소 시점, 소성 이력, 임계 파괴, 호수 낙하, 미션·점수, 대사, 개념 페이지, 종료·랭킹, 배치, 휴대폰 배치 등)

## 번외 파일 `index_plus.html`

본 파일(`index.html`)에 UX 를 더 얹어 본 실험판. 핵심 수치 타일(M · σ/σ_y · δ), 다음 미션 강조와 '하는 법' 안내(항목 클릭), 점수 +N 팝업, 재료 칩 색 점, 키보드 단축키(1~5 하중물 · U 제거 · R 교체 · V 시점 · G 가이드). 역학 계산은 본 파일과 같다.
검사 기록은 `qa/` (요청서 `review_request_*.md`, 스크린샷 `qa/shots/`, 번외 파일 5해상도 스크린샷 `qa/shots_plus/`) 에 있다.
